# Recorded academy claims and evidence

The Learning tab includes the optional `scientific_claims` history. A run that
never records it has no academy evidence section. A missing or inconsistent
selected observation is unknown; final world state supplies no historical
substitute. The source must equal snapshot turn minus one. Actual trial funding,
resolution, input and evidence-receipt dates must already be known. A cancelled
trial can retain its future scheduled completion date as a plan.

The inspector shows contextual propositions, local confidence, dependence-group
accounting, paid adoption allocations and dated trial resolutions. Soil/water
bands, crop, season, climate, crew and protocol remain attached to each claim
and resolved trial. Confidence is an institutional policy score, not universal
truth. The dependence-group count does not qualify independent world units.
Sham controls produce measurements with no treatment information and still use
ordinary posterior updates; withholding information is a separate control.
Belief confidence/groups and the last evidence used are current-context policy
values. A seasonal/ecological/climate mismatch can return the prior and no
currently applicable evidence while older receipts remain archived. The table
does not describe this as forgetting or absence of all historical receipts.

The observation's publication rule is labelled separately. Legacy exports that
omit `publication_rule` use documented `current-context-v1`: the registered
context must remain applicable when a result is due. Explicit `funded-context-v2`
can publish a valid measurement recorded at funding after current conditions
change, provided academy access remains available. Its archived funding context
does not imply that current-context policy confidence uses that evidence now.
Unrecognized future values remain explicitly unknown rather than inheriting
either known rule. Synthetic reader-only v2/future-policy examples contain zero
observations and are separate from the actual controlled/natural run fixtures.
The label describes the selected snapshot's policy; older resolution rows are
not assumed to have used that same rule.

Trial calculations and noisy measurements have separate labels. A resolution
is not added grain harvest or proof of a world effect. Cancelled/failed records
show their actual status, reason and cost without presenting completed
measurements. Parent trial IDs, source data and environment/dependence blocks
remain inspectable. Historical resolution buttons seek the snapshot that saved
the outcome, never a later world or an earlier uncompleted tick. Stale receipt
arrays do not create additional trials. Lists initially show 40 resolutions and
can expand to all recorded history through the selected snapshot.

Spending charts stop at the selected observation, with null gaps for unknown
history. Trial and adoption spending are actual cumulative treasury payments.
Allocation payments belong to this completed turn; the whole seat payment is
carried on the first recipe row and is summed once. The viewer does not infer
that a zero on another recipe is a separate free programme. Names come from
the observation itself; missing names use explicit indexes rather than final
world ownership.

All seven science Event kinds use the completed-tick clock shared with the
other expansion inspectors. Event feeds, provenance, pinned headers/body,
accounts and navigation observe simulation S only at snapshot S+1. Planned
dates and unrelated legacy event clocks retain their existing interpretation.

`scientific_claims_observations.json` is a byte-preserved copy of the producer's
14-turn controlled mechanical fixture from runtime `35c58455`. It records
original and replication trial calculations, actual receipts and paid effort;
it explicitly carries no scientific world qualification. Tests check the four
dated resolutions, eight treasury units spent on trials, five spent on effort,
and the ten allocation rows whose payments sum to five. The shared transport
fixture also contains empty science and transaction-receipt shape stand-ins;
those stand-ins qualify transport only, not native behavior or merchant finance.

production build. Desktop (1440px) and mobile (390px) browser checks then used
the actual complete 26-turn controlled bundle from simulation `97b6a051`.
That run's initial academies/practice/grain eligibility and all-DEVELOP choices
are explicit interventions; agents were off, and the bundle is mechanical
evidence without scientific world qualification. Ordinary run capture supplied
every historical world snapshot, with no final-state backfill.
