## 1. Goal and scope
Remove 2,096 lines of unreachable legacy components and the dead exports they leave behind, close three viewer hygiene gaps (live WebSocket shape check, dependency declarations, lint scope), and replace copied validator and panel boilerplate with shared primitives. No change to simulation, bundle schema, CLI flags or viewer behaviour. Excluded: demo-file moves to `src/demos/` (scout 24 finding 12), a11y fixes, atlas zoom, `entityHistoryNavigation` rewrite.

Split by pin level. Everything is planned **unpinned first**. Enforced-pinned files are separate PRs that wait for PIN-1; the plan never rewrites a hash.

## 3. Design
**DEAD-1.** Delete the nine components, the three test files, the legacy `describe` block and the unused `SetupLobby` import in `FeatureRequests.test.tsx`; drop `d3-force` and `@types/d3-force` from `package.json` and regenerate the lockfile with npm (lockfile edits are never by hand). Remove leftovers the export script reports.

**DEAD-4.** Unpinned PR: delete `factionColorDark`, `movementsOf`, `DEPOSIT_REASONS`/`MOVE_GROUPS` if still unused, `templeEventText`, `faiths.reformKind`, `apprenticeshipAt`, `hasGovernanceRecord`, `investigationBookmarkReference`, `famineSpans` with their test references; drop `export` from internal-only value exports; remove the `useBundle` re-export. **Keep** declared test seams (`setDecodeWorkerFactory`, `setReferenceObjectPatches`, `clearComparisonGallery`) and mark them `/** test seam */`; deleting them is not a goal. Pinned follow-up (after PIN-1): `recipePreparedMismatch` in `whatIf.ts`, `comparisonWarnings`, `entityRunMatching`, and any pinned-lib internal exports.

**FIX-8.**
1. `lib/liveMessages.ts` (new, unpinned): `parseLiveInit(msg)` and `parseLiveTurn(msg)` returning `{ok:true,value}|{ok:false,reason}`. Turn: `turn` finite integer ≥ 1, `civ_stats`/`region_control`/`relationships` records (`isRecord` from `bundleValidation.ts:6`), `events`/`named_events` arrays when present. Init running state: `world_state` record with `regions`/`civilizations` arrays, `history` array of records with numeric `turn`, `metadata` record. Do not call `validateBundleStructure` on live data: live init legitimately has partial fields. Reuse its field helpers by exporting them from a small `lib/recordGuards.ts` (CON-9).
2. Wire into `useLiveConnection.ts:258-300` (replace `any` with `unknown`; on rejection `console.warn` and drop, as non-JSON already does). **Enforced pin, so this edit waits for PIN-1.** Behaviour change: malformed messages now dropped instead of appended as turn 0 — classify as a hardening with a ledger line, not byte-identical.
3. Lint: keep `"lint": "eslint ."`; add an `.mjs` block to `eslint.config.js` (`files: ['scripts/**/*.mjs']`, `globals.node`, no TS rules). Fix or `eslint-disable` findings in the same PR; if the findings count is large, scope the glob to the three small scripts and file a follow-up.
4. `esbuild`: add as devDependency `^0.28.2`, `npm install --package-lock-only` (resolves to the already-locked version; no new package).
5. `playwright`: **not** added to `dependencies`. Add `viewer/scripts/lib/playwright.mjs` that `require`s it and, on failure, throws "Playwright is not installed; install it globally (cloud sessions have it) or `npm i --no-save playwright`"; update the 9 scripts to use it; document in `viewer/README.md`. Optional alternative if the owner wants a declaration: `peerDependencies` with `peerDependenciesMeta.optional=true`, range `>=1.40`, which declares without installing. Recommend that line plus the helper (open question 1).

**CON-9.**
- `lib/recordGuards.ts`: `isRecord` (move source of truth; `bundleValidation.ts` re-exports), `finite`, `amount`, `integer(x,min?)`, `count` (isInteger ≥ 0), `safeCount`, `safeInteger(x,min?)`. Each module imports the variant matching its current body. Equivalent spellings collapse to one; the two `isSafeInteger` spellings map to `safeCount`. No accepted-value change anywhere: that is the acceptance test.
- `lib/livelihoodRecord.ts`: `readLivelihoodRecord(snapshot, key): Record|null` doing the envelope only (`livelihoods` record, `schema_version===1`, `x` record, `x.schema_version===1`). Per-module source-turn rules stay local because they differ (`source_turn+1` vs `completed_turn`). Migrate unpinned `*At` readers; pinned ones later.
- `lib/download.ts`: `downloadText(filename, text, mime)` (create object URL, click, revoke). Start with `InvestigationPacket.tsx` (unpinned); `CompletedRunCompare.tsx:115` and `WhatIfPanel.tsx:86` later.
- Systems primitives: `components/systems/formatters.ts` (`show`, `percent`, `words`), `SystemSection`, `SystemTable`, `usePaged`. `SystemPanelFrame` only if a second pass shows a stable shape. Pilot on three unpinned panels, then roll through unpinned panels; pinned panels after PIN-1.
- AppShell: move `:127-492` helpers to `lib/shellFeed.ts` (chronicle feed, narrated spans, era bands) and `lib/atlasLayout.ts` (layout, connections, centroids, campaign links, `sortCivilizations`); `appShellHelpers.ts` already holds `buildEventFeed`. Memoise `buildChronicleFeed`, `buildCivilizationViews`, `computeAtlasLayout`, `buildEventFeed` with `useMemo` keyed on `[bundle, currentTurn, …real inputs]`. Hook-lint (`react-hooks`) will flag missed deps. Add `snapshotAtTurn(history, turn)` to unpinned `lib/bundleIndex.ts` (WeakMap on the history array → turn→rows map, same "exactly one row" rule) and use it at AppShell :696/:726. Leave `exactSnapshot` in pinned `historyComparison.ts` untouched until PIN-1, then delegate it.
- Validation: one history/event pass that records the first structural error and first viewable error separately, returns structural first. This preserves current message order exactly because `validateViewableBundle` runs only after the structure check passes (`bundleFile.ts:96-100`, unverified here, confirm in step).

## 4. Compatibility
No bundle, checkpoint, CLI or import-path change. Old bundles must load identically: guard variants preserve accepted values. `bundleValidation.ts` keeps its exports.

## 5. Pins and preflight
Run `.venv/bin/python scripts/refactor_preflight.py <paths>` per PR. Unpinned-slice PRs 1-5 must report no `ENFORCED` line; the plan includes a script that fails if any touched file does. Pinned slice (PR 6): every touched file is edited only after PIN-1; if PIN-1 is declined, option B means one reviewed inverse layer per file, and PR 6 is dropped to the 4 highest-value files.

## 6. Classification
Refactor except: WebSocket guard (hardening, malformed input now rejected; ledger line); lint scope and dependency declarations (tooling). Baseline: vitest count before/after, `tsc` clean, build size from `perf-viewer.mjs sizes` (d3-force removal should shrink the bundle only if it was in the entry chunk; it was dead so expect no change), and `viewer-equivalence.mjs` for the shell memo work.

## 7. Tests
New: `lib/__tests__/recordGuards.test.ts` (each variant against 2^53, NaN, -0, arrays, null), `livelihoodRecord.test.ts`, `liveMessages.test.ts`, `download.test.ts`, `bundleIndex.test.ts` additions (duplicate-turn → null), `systems/__tests__/formatters.test.ts`, `usePaged.test.tsx`, bundle-validation order test (structural error at snapshot 9 vs viewable at 2). Changed: `useLiveConnection.test.ts` (malformed turn dropped), deletions per DEAD-1.

## 8. Risks and rollback
Memo deps missing a mutated-in-place input (live bundle mutates arrays but replaces identity: confirm per memo). Lockfile churn: review `git diff package-lock.json` for only d3-force and esbuild changes. Each PR reverts independently. Open: (1) playwright declaration style; (2) how many findings the new `.mjs` lint block raises (unmeasured; lint was not run); (3) whether demo-only moves join this workstream.
