## 3. Design

**3.1 HYG-1 status block.** Add `## Current status` at the top of `docs/CONTINUATION.md`: date, last verified `main` SHA, last merged PR, last verified Tests run, gate state (200-seed gate not run), and one line "update this block in the ledger commit after each merge". README "Current Status", the `AGENTS.md` opening paragraph and the `docs/RECOVERY.md` "Updated" line link to it and carry no PR numbers or SHAs. RECOVERY keeps its source-identity entries; they are labelled historical. Move `docs/CONTINUATION.md` from `## Historical checkpoints` to the end into `docs/superpowers/progress/continuation-history.md` byte-for-byte, and leave a pointer. Repoint `docs/RECOVERY.md:305`, `README.md:30`, `docs/README.md:13`. Do not touch JSON or dated integration records that name `docs/CONTINUATION.md`; the path still exists. README lane text: defer to DEVELOPMENT.md for the guarded lane without removing strings `tests/test_native_build_lanes.py` pins.
**3.2 HYG-2.** Append `*.log`, `*.cpuprofile`, `.coverage`, `htmlcov/`, `.mypy_cache/`, `.ruff_cache/`, `.hypothesis/`, `*.so`, `*.pyd`. Until HYG-7 lands add `!docs/**/*.log` and `!docs/**/*.cpuprofile` so evidence logs can still be committed; HYG-7 removes the negations.
**3.3 HYG-3.** Archive in place: a new `docs/superpowers/audits/README.md` indexes current (2026-11-08) versus historical audits, and the 03-29 and 04-02 audits get the same "Historical snapshot" banner `masteraudit.md` has. No rename or move, so no link breaks. Fix the four `feature-options.md` spots (compute counts from the registry, do not guess) and the archive README wording. Leave `"post-M18"` as is: changing it alters serialized report output for no consumer. Record it as an explicit non-change.
**3.4 HYG-4.** `concurrency: {group: tests-${{ github.ref }}, cancel-in-progress: ${{ github.event_name == 'pull_request' }}}` so pushes to `main` and lead branches are never cancelled. Pin `rust-toolchain` to `with: toolchain: 1.85.0` at a SHA ref, and move all `uses:` to SHAs (existing SHAs: checkout `11bd7190`, upload-artifact `ea165f8d`, cache save/restore `0057852b`; resolve the rest with `gh api`). Jobs outside the four native ones change freely. For the four native jobs, extend `test_standard_native_delegation_keeps_the_qualified_v2_bodies` with a reviewed `uses`/`with` projection map, the same pattern as the `python-version` exception; never edit `.yml.in`.
**3.5 HYG-5.** Keep `step()` and the "continue" behaviour. Record failed step names, print a `== setup summary` block, and exit non-zero only when `CHRONICLER_SETUP_STRICT=1`. The scout and synthesis ask for an unconditional non-zero exit; I advise against it because an environment setup script that fails stops the cloud session from starting. Add the missing `command -v uv`/`npm`/`cargo` pre-checks as recorded failures. Replace `|| exit 0` with a recorded failure.
**3.6 HYG-6.** Move 15 scripts (`benchmark_perception, cw_program_profile, guilds_identity, learning_cohorts_funnel, m53_baseline, provenance_identity, prune_dead_civ_snapshots, recovery_skills_examples, relocation_costs_funnel, watershed_activation, watershed_calibration, watershed_replay, world_systems_report, diplomacy_identity, epidemiology_identity`, about 2,700 lines) to `scripts/archive/`, add one manifest entry each, fix root lookups to `parents[2]`, and update `scripts/README.md`. Keep the rest. Workflows: keep all nine in place. Add `docs/workflows/README.md` stating which are live (`tests.yml`, `validation-gate.yml`, `workflow-semantics.yml`) and which are one-run records.
**3.7 HYG-7 (after DEC-8).** *DEC-8 asks:* (a) may raw run output leave HEAD, with a SHA-256 manifest and a release asset as the retrievable copy (recommended); (b) which host holds the asset (GitHub release on this repo, or an archive branch); (c) is a history rewrite wanted (recommended no). Default if unanswered: do nothing. Offload the 69 logs, the `.cpuprofile` and every `metrics.jsonl` except `connected-world-screens-cw3b/held`. Procedure: build `evidence-offload-2026-11.tar.zst` plus `docs/superpowers/progress/EVIDENCE-OFFLOAD.md` listing path, size and SHA-256 per file, publish the tarball as a release asset on a dated tag, then `git rm` the originals and drop the HYG-2 negations. Receipts' hashes stay checkable by restoring the tarball. Keep one summary `.md` per screen family (already present). Honest limit: history still holds the bytes, so clone size drops only if history is rewritten, which is out of scope.
**3.8 HYG-8.** Moves are limited to the 160 additions. Fetch `native.xml` junit artifacts from three recent `main` runs (retention 14 days), sum `testcase time` per module, and choose additions on shard 0 to move to shard 1 until the shard totals match within about 10 percent (target ~10.5 min each from 14.2 / 6.9). Edit the manifest `shards` lists and the `additions` literal in the same PR; `old_owners` stays untouched. The change is an ownership correction, not a hash rewrite.

## 8. Risks and open questions
Pinning 1.85.0 may fail on the locked crates; CI is the proof, fallback is a pinned newer stable (state it in the PR). Release-asset hosting needs an owner (DEC-8). Per-module timings need network access to GitHub artifacts. Hidden risk: a comment in `src/` naming a moved script (`watershed.py:190,545`, `provenance.py:818`) goes stale; update only if the preflight shows no enforced pin. Rollback: each PR reverts independently.
