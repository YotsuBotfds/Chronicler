**Map**

- Benches: tick_bench and cache_bench (declared in Cargo.toml). Examples: scale_bench (auto-discovered) and flamegraph_run.

**Findings**
1. [med] [bug] Culture distribution saturates at u16. `compute_cultural_distribution` uses `saturating_add` on u16 (culture_tick.rs:95-104). Those weights drive sampling in `drift_agent` (culture_tick.rs:192-198). At 1M-agent scale a region can hold more than 65,535 agents, so a dominant value flattens. Action: widen to u32 and document it as a correction. Output is unchanged below 65k per region.
2. [med] [fragile] Float comparators are not total. `sort_by(... partial_cmp(...).unwrap_or(Equal))` appears at formation.rs:789-793 (reference marriage path, reached for non-finite positions per formation.rs:1112), movements.rs:452-456 and politics.rs:1407. NaN makes the order non-total. Rust 1.81 and later may panic on that, and the crate sets rust-version 1.85. Action: use `total_cmp`.
3. [med] [fragile] Hand-rolled SHA-256 is tested only on empty input. politics.rs:745-~845 has no `sha2` dependency (Cargo.toml). The only test is politics.rs:3270-3277, which checks the first 4 bytes of sha256(""). The multi-block path (inputs over 55 bytes) is unverified, and it feeds seeds at politics.rs:1147, 1377 and 1835. Action: add NIST vectors (56, 64 and 1000 bytes) before touching it, or switch to `sha2` with a Cargo.lock update.
4. [med] [duplication] `stable_hash_int` does not match its docstring or Python. The docstring (politics.rs:720-726) promises Python's repr-joined payload. Call sites hand-build `'{}'`-quoted strings (politics.rs:1377), with no repr escaping. utils.py:25-41 uses repr, so a civ name containing `'` or `\` hashes differently (`repr("Ka'lo")` is double-quoted). Endianness also differs: this helper reads BE (matches utils.py:41), while the perceived-stat seed reads LE (politics.rs:1147-1149). Action: move repr rules into the helper and add a parity test with apostrophe names. Whether real names contain apostrophes is unverified.
5. [med] [dead-code] Stale Python persecution constants. religion.py:43-44 defines `PERSECUTION_REBEL_BOOST = 0.30` and `PERSECUTION_MIGRATE_BOOST = 0.20`. Nothing reads them (grep across src, tests and scripts). The live Rust value is agent.rs:221 (0.18), used at behavior.rs:1065. Action: delete the Python pair.
6. [med] [dead-code] Python formation fallback is unreachable in production. agent_bridge.py:1290 sets `rust_owns_formation = True` unconditionally. The branch at simulation.py:2576-2600 runs only when a test sets it False (tests/test_regional_population.py:188, tests/test_turn_artifact_lifecycle.py:123). relationships.py:201-415 (`check_*_formation`, `form_and_sync_relationships`) is therefore test-only. Action: confirm the test dependence and delete, or move behind an explicit fallback flag. This is a policy decision for the owner.
7. [med] [perf] Exact spatial drift is O(N²) per region. Each agent scans its 3x3 block of the fixed 10x10 grid (spatial.rs:1346-1400 and doc). That is about 0.09·N² pair tests per region per tick, so roughly 9e6 at 10k agents in one region. Fast mode bounds this (scale.rs FAST_DRIFT_TARGET_PER_CELL). Action: document the cost and make the exact grid population-aware, or keep exact as the reference only. Timing is unmeasured.
8. [low] [perf] Formation inner loop does avoidable work. formation.rs:1601-1603 `sort_by_key(mix_hash)` recomputes the hash on every comparison, so use `sort_by_cached_key` (same stable order). `agent_bonds_this_pass: HashMap<usize,u8>` (formation.rs:1623-1735) is only point-accessed (no iteration), so a `Vec<u8>` indexed by slot gives identical output. The pair loop is O(n²) per region every 6 turns (formation.rs:1636-1660).
9. [low] [dead-code] Dead constants and tests-only helpers. ecology.rs:19-32 holds `FOCUS_NONE`, `TERRAIN_MOUNTAINS` and `TERRAIN_FOREST`, with no non-test use, behind `#[allow(dead_code)]`. region.rs:4-16 has `Terrain::from_u8` (test-only). Both files are pinned: livelihoods_rs5_source_inverse.json records sha256 for ecology.rs and region.rs. Run `scripts/refactor_preflight.py` first.
10. [low] [dead-code] Public test-only API. No non-test callers and no FFI use: `formation::marriage_scan` (formation.rs:568), `spatial::spatial_drift_step`, `_with_mode` and `_with_kernel` (spatial.rs:1228-1277), `relationships::drift_relationships` (relationships.rs:288), `relationships::remove_symmetric` (relationships.rs:275), `named_characters::find_candidates` (named_characters.rs:148), `region::is_adjacent_to` and `relationships::is_symmetric`. Callers are tests/*.rs and in-file tests. Action: move under `#[cfg(test)]` or repoint the tests.
11. [low] [duplication] `marriage_scan_reference` (formation.rs:681-731) repeats the per-region loop of `marriage_region_reference` (formation.rs:734+). Action: make the reference a loop over that helper.
12. [low] [fragile] Adaptive migration binary search assumes sorted, unique rows. `AdaptiveMigration::score` (adaptive_migration.rs:14-17) relies on sorting. `new()` does not sort or dedup. The FFI sorts with `sort_unstable_by_key` on (id, dest) (ffi/mod.rs:1057) and does not reject duplicates, so the chosen duplicate depends on sort internals.
13. [low] [fragile] Spatial diagnostics truncate. `hash_max_cell_occupancy` is `c.len() as u16` (spatial.rs:1314). It is exported (ffi/mod.rs:2579) and read by scripts/agent_scale_benchmark.py:122, and it truncates above 65,535 agents in one cell. `attractor_occupancy` runs every tick, outside the profiling flag (spatial.rs:1326-1360). A grep found no Python consumer of `attractor_occupancy_flat`.
14. [low] [duplication] Pinned hash and cross-language constants. tests/test_health_care_policy.py:1018-1027 pins SHA-256 of health_care.rs, health_care_observation.rs, pool.rs, tick.rs and ffi/mod.rs, so editing any of them means re-deriving the pin. agent_movements.py:137 mirrors `RELIEF_TURNS` from movements.rs:96 by comment only. Ecology tables (SEASON_MOD, CLIMATE_CLASS_MOD, TERRAIN caps, default tuning) were checked and match (ecology.rs:52-99 against resources.py:356-383 and ecology.py:63-73). Only the comment-based links are fragile.

**Simulation depth**
- Spatial drift has no barriers. Rivers, roads and terrain do not block movement; attractors are the only spatial pull (spatial.rs:224-449).
- Culture has no resource-phantom counterpart in Python. `ENV_BIAS_TABLE` (culture_tick.rs:31-45) exists only in Rust. Also, `phantom_base = (pop·0.05) as u16` (culture_tick.rs:123) is zero below 20 agents.
- Movement decisions are Python-only (agent_movements.py). The native pass handles only membership, so spread and lapse are not coupled to the agents' decision inputs.
- Memory is 8 fixed slots with half-life decay (memory.rs:11), with no salience-based forgetting.

**Confidence** Verified by grep across src, tests, scripts and chronicler-agents/tests, and by reading the cited lines. Nothing was built or run. The repr divergence in finding 4 is inferred from code, with Python repr checked directly. The Rust 1.81 sort-panic behaviour comes from external knowledge.
