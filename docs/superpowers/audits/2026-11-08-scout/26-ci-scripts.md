## 26 CI workflows, scripts and dependencies
**Map**
- `.github/workflows/`: 9 files, 2,495 lines. `tests.yml` (559 lines) is the only always-on gate: push and pull_request. Its jobs are Python bounded offline, Python no-Rust, a native wheel build, two native shards, an aggregate, Python native, Rust and Viewer.
- `validation-gate.yml` runs weekly (cron `0 8 * * 0`) and on dispatch, with a 360-minute timeout. `workflow-semantics.yml` runs actionlint on push and PR.
- Six workflows are branch-gated or dormant. Each triggers only on a push to one dated `lead/*` branch, or on dispatch: `native-two-shards.yml`, `native-two-shards-v2.yml`, `kin-decision-capture.yml`, `native-functional-smoke.yml`, `named-context-benchmark.yml`, `paired-context-benchmark.yml`.
- `scripts/`: 173 `.py`/`.sh` files, about 47k Python lines. 36 scripts sit in `scripts/archive/` (5,517 Python lines plus one 164-line shell script). `scripts/testing/` holds the guard, witnesses and two manifests.
- Setup: `setup.sh` (183 lines), `setup.bat` (200), `scripts/cloud_setup.sh` (33). Lockfiles `uv.lock`, `chronicler-agents/Cargo.lock` and `viewer/package-lock.json` are tracked.

**Findings**
1. [high] bug — The one failed `tests.yml` run that was not a pull-request branch was run 42417373801, head `89e80e8c` on `codex/cw-rework`. It failed deterministically: `tests/test_screen_runner.py:1066` asserts a registry content hash, and the failure cascaded to five jobs (CI job 128538275062 log). Later pushes to the same branch passed (runs 42418338689 onward). Action: resolved in history, but a pinned hash must not be rewritten to make a change pass.
2. [med] flaky — No flakiness signal in the last 60 runs. All are attempt 1, and no failure is followed by a success on the same SHA. Failures without a later same-SHA pass: 42389696392 (`79a7f411`), 42388560576 (`063658b9`), 42331445447 (`706e7af4`, native shard 0 "retained first result"; cause not in the log tail, unverified). Four runs on `codex/cw-lead` were cancelled (42391757272, 42386325619, 42386243059, 42386034408). No workflow declares `concurrency:`, so the cancel source is unverified. Action: add an explicit `concurrency` group with cancel-in-progress to `tests.yml`.
3. [high] duplication — `native-two-shards.yml` and `native-two-shards-v2.yml` are both 519 lines and differ only in the branch name and display name. Both repeat the shard jobs already in `tests.yml`. Each ran once, on 2026-10-29 (runs 40858749837 failure, 40863008464 success). The `docs/workflows/*.yml.in` copies are pinned byte-for-byte by `tests/test_native_ci_shards.py:437,613` and `tests/test_native_build_lanes.py:284`. Action: keep one record; delete the other only after the pins are updated.

[med] dormant — `kin-decision-capture` (146 lines), `native-functional-smoke` (137), `named-context-benchmark` (192) and `paired-context-benchmark` (185) each ran once, on 2026-10-30 (runs 41009457209, 41002421072, 41002425214, 41016638445). Shard 1 takes 6.9 min, so the split is unbalanced by about 7 minutes. Other jobs: bounded offline 9.7 min, no-Rust 7.8 min, viewer 4.6 min, Rust 1.0 min. Action: rebalance shard ownership using recorded durations; `native_ci_shards.py` owns the split and is pinned by `scripts/testing/native_shards_manifest.json`.

Some actions are SHA-pinned and others are tag-pinned. Node 20 deprecation warnings appear in logs. Action: pin the toolchain to 1.85 and standardise on SHA pins.

9. [high] fragile — `scripts/cloud_setup.sh` uses `set -uo pipefail` without `-e`. Each `step` prints `!!` and continues, and the script always exits 0 (lines 9-33). `cd ... || exit 0` also hides failure. There is no check for `uv` before use. `setup.sh` is fail-fast (`set -euo pipefail`), so the two disagree. Action: track failures and exit non-zero at the end; keep continuing past failures.
10. [low] fragile — `setup.sh` without uv falls back to an unlocked `pip install -e` plus unpinned `pytest pytest-asyncio` (line 77). It does warn. `setup.bat` checks errorlevel consistently. Action: none needed beyond the warning.

Verified: `openai` at `src/chronicler/llm.py:100`, `anthropic` at `llm.py:301`, `google-genai` at `llm.py:307`, `websockets`, `scipy`, `arro3` and `pytest-asyncio` (`tests/test_live_integration.py:184`). 12. [low] docs — `scripts/archive/README.md` says "No test or CI workflow runs them", but `script_smoke.py` runs the safe entries from the manifest. Action: correct the wording.

**Simulation depth**

- `generate_viewer_fixture.py` is manifest-pinned but not run in CI. A check that the viewer fixture still regenerates would tie the viewer to the simulation output.
