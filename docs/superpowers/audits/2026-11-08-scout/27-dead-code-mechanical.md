**Simulation depth**
- Rust `TERRAIN_MOUNTAINS`, `TERRAIN_FOREST` and `FOCUS_NONE` have no use in the native crate. Grep alone cannot show whether terrain-specific ecology is absent from the native path, so this needs a behaviour check.
- The `analytics.py` extractors (item 5) are the kind of per-turn diagnostics a viewer or the run report could show. Wiring them to an output would turn test-only code into an observable.
- Unreachable experiment modules (item 2) describe measurements (governance, health-care observation, expansion comparisons) that nothing in the turn loop computes. Their absence from the live path is a real limit on the owner's wish for a broader simulation.

**Confidence**
Verified by grep and AST: reachability (29 unreachable), name-level usage, framework and registry dispatch exclusions, pin levels for every candidate, and cargo (zero warnings). Inferred: the Rust constant removals are safe because the compiler sees no use, but they are also in an enforced witness. Not verified: runtime behaviour of any deletion, and the historical compatibility of `backfill_ids` and `run_chronicle`.
