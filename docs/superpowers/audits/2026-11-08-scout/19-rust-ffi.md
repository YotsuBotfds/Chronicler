## 19 Rust FFI surface and crate configuration
**Map**
- `chronicler-agents/src/lib.rs:152-156` registers three pyclasses (`AgentSimulator`, `EcologySimulator`, `PoliticsSimulator`) in the `#[pymodule]`. No free `#[pyfunction]`s exist in the crate.
- `src/ffi/mod.rs` is 5,855 lines. Non-test code is about 4,750 lines, with one `#[pymethods]` block at lines 271-4736 (about 130 methods). The test module begins at 4758 and runs to about 5,824. `src/ffi/batch.rs` (1,417 lines) holds Arrow parsing and build helpers. `schema.rs` (482 lines) is schema constructors only, with no validation. `ecology_sim.rs` (529) and `politics_sim.rs` (127) are the off-mode wrappers.
- Python callers are in `src/chronicler/agent_bridge.py`, the main consumer, plus `remittances.py` and `household_retail.py`. Tests in `tests/` call many more methods directly.
- Integration tests `chronicler-agents/tests/m38a_ffi.rs` (3 tests) and `test_m53_ffi.rs` (2 tests) exercise the public Rust API, not PyO3. Most FFI coverage is inline `#[cfg(test)]` code.
- The release profile sets `codegen-units=1`, `lto=true`, `opt-level=3`, with no `panic` setting.

**Findings**
1. [med, dead-code] Eight exported methods have zero Python callers under `src/chronicler/` or `scripts/`. They are called only from Rust or `tests/`: `get_community_ties` (mod.rs:2926), `has_pending_learning_attendance` (mod.rs:478), `movements_enabled` (mod.rs:793), `pending_targeted_death_count` (mod.rs:798), `set_spatial_sort_profiling` (mod.rs:1149), `spatial_sort_profiling` (mod.rs:1155), `snapshot_is_cached` (mod.rs:2109), `work_reservation_conflicts` (mod.rs:427). Tests found: `tests/test_community_anchoring_native.py`, `test_agent_movements.py`, `test_war_integration.py`, `test_rust_turn_speed.py`, `test_agent_bridge.py`, `test_columnar_paths.py`. Fixture `tests/fixtures/livelihoods_*_source_inverse.json` also names some. Action: keep as diagnostics or delete with their tests after the fixtures are reviewed.
2. [med, duplication] Ten local `macro_rules!` column readers are defined inside separate methods in mod.rs (lines 1184, 1193, 1202, 2440, 3447, 3455, 3463, 3471, 4317, 4326). Four more are in batch.rs (181, 282, 336, 1245). Each repeats `column_by_name` → `downcast_ref` → `PyValueError` with slightly different messages. Action: merge into one module-level macro with a type parameter.
3. [med, fragile] Region and civ row parsers check column presence and type but not nulls or value ranges. `parse_region_input_batch` (batch.rs:278-325) reads `region_idx` with `.value(i)` and never checks that it equals the row index, is unique, or is in bounds. `parse_civ_input_batch` (batch.rs:177-200) does the same for `civ_idx`. A null or duplicate index is accepted silently. Action: add null and index-consistency checks at parse time.
4. [med, bug] Unguarded index in politics pass: `politics.rs:1030` and `:1053` index `live_civs[observer_idx as usize]` with no length check. Other sites are guarded (`:1024`, `:1105`, `:1784`). Whether `observer_idx` is always in range is unverified. If not, the panic becomes a Python `PanicException`, not a process crash, because the release profile does not set `panic=abort`. Action: add a bounds check or prove the invariant.
5. [low, fragile] Remaining `unwrap()`/`expect()` on non-test FFI paths are guarded: `mod.rs:213` (Rust `new`, which `py_new` at 274 pre-validates), `mod.rs:617` (guarded by the all-zero check at 603), `mod.rs:2402` (`binary_search`, guarded by the `requested` build and `slots` fill), `mod.rs:3650-3737` (guarded by `all(is_some)`), and `mod.rs:4366`/`:4421` (buffer initialised just above). Unverified: `mod.rs:4785` and `:4806` (`RecordBatch::try_new(...).unwrap()` in helpers at 4765-4810). I did not check whether those helpers are `#[cfg(test)]`-gated.
6. [low, bug] Error mapping is consistent. Input validation returns `PyValueError` (about 157 sites in mod.rs, 20 in batch.rs). Arrow errors go through `arrow_err` (batch.rs:24-26) to `PyValueError`. Rust panics surface as PyO3 `PanicException`. No `unsafe` appears in `src/ffi/`. The only `unsafe` in the crate is AVX code in `spatial.rs:1164-1186`, outside the FFI.
7. [low, fragile] Shape guard present for region state: `set_region_state` (mod.rs:1164-1177) refuses row-count changes before invalidating caches. Keep this pattern. Several other batch entry points lack an equivalent row-count check (unverified exhaustively).
8. [med, fragile] Checkpoint compatibility is tied to struct layout. `persist::py::describe::<Self>()` produces a layout fingerprint (mod.rs:664, ecology_sim.rs:52, politics_sim.rs:40). Adding, removing or reordering fields of the three pyclasses changes the fingerprint and makes older checkpoints refuse to load. Action: any field change needs a state-version bump and a compatibility note.
9. [low, duplication] Getter/setter boilerplate is small. Only four `#[getter]`s and three `#[pyo3(get)]` fields (mod.rs:129-138, 817, 848, 874, 1154) exist. Most of the 59 `get_`/`set_` methods are hand-written and carry their own argument unpacking. A macro would help mainly for the `take_*`/`cancel_*`/`set_*` triads (for example `cancel_adaptive_*`, `cancel_food_allocation`, `cancel_relocation_policy`). Estimated saving is about 40-80 lines; not verified by counting.

**Simulation depth**
- Parse-time validation (null, duplicate and range checks on `region_idx`/`civ_idx`) would let the Rust side accept richer inputs without silent corruption, which broadens what the bridge can safely carry.
- The politics topology path (`politics.rs:1030`) is the place to add bounds-checked observer lookups before adding more cross-civ perception rules.
- Ecology and politics off-mode wrappers expose only a subset of the agent pool API; extending them is the cleanest route to depth without enlarging `AgentSimulator`.

**Confidence** — Verified by grep and reading: the export list, the zero-caller list (grep across `src/chronicler`, `scripts`, `tests`, `chronicler-agents`, `viewer`), column-macro counts, unwrap/expect sites, and Cargo.toml contents. Inferred: panic-to-exception behavior (from PyO3 defaults and the absence of `panic=abort`). Unverified: politics `observer_idx` invariant, `mod.rs:4785`/`:4806` gating, arrow/pyo3-arrow version alignment, line savings for the macro merges. No cargo commands were run.
