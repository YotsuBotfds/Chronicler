## 12 Ecology, climate, geography, watersheds, fisheries

**Map**
- `ecology.py` (1313 lines) is the Phase 9 tick. With a native runtime, `tick_ecology` (ecology.py:1213) calls `_tick_ecology_rust` (1233) and Rust `ecology.rs` (1462 lines) does the core math. Without one (`--agents off`, pure Python), `_tick_ecology_python` (1060-1206) runs the same formulas in Python.
- Python post-passes run in both paths: famine and hunger (`_check_famine_yield`, 263-395), soil floor, counters, terrain succession, population sync.
- `climate.py` (460): a 75-turn, 4-phase global schedule (`models.py:298`), 12-turn seasons (`resources.py:352`), regional harvest shocks by cluster (`climate.py:68-200`), and four disaster types (`climate.py:242-247`).
- `geography.py` (873): procedural Voronoi/raster geography, rivers, sea zones, latitude bands, and procedural roles (betweenness, `geography.py:522`).
- `adjacency.py` (253): template-world graph utilities. Only `compute_adjacencies` and `classify_regions` are used in production, from `world_gen.py:536,543` and `scenario.py:476`.
- `watershed.py` (1168) and `watershed_state.py` (311): a conserved water account, Phase 9, `--watershed` with `record_only` or `flow` modes.
- `experimental/fisheries.py` (334) and `fisheries_bridge.py` (16): a per-slot fish stock, default-on for new CLI worlds (`main.py:1641-1647`).

**Findings**
1. [high] docs/contract: Fisheries are default-on for new CLI worlds. `fisheries.py:26` sets `DEFAULT_ENABLED_FOR_NEW_WORLDS = True`, and `main.py:1642-1647` applies it. AGENTS.md says experimental features stay default-off. The module docstring cites a promotion doc, so this may be intended. Action: owner confirms the promotion. `NEW_WORLD_REFERENCE_WORKERS = 100` is still marked `[CALIBRATE]` (`fisheries.py:34`).
2. [med] duplication: Two live copies of the ecology formulas. The Rust tick is authoritative when a native runtime is present (`ecology.py:1226-1229`). `_tick_ecology_python` (`ecology.py:1060-1206`) is authoritative for `--agents off` and shadow-free pure Python runs. Parity tests need the native build (`tests/test_ecology_parity.py`). Action: generate shared constant tables from one source (see the streamlining table).
3. [med] test-gap: The legacy oracle (`tests/legacy_ecology_oracle.py`, 474 lines) is a frozen pre-M54a copy used by `test_ecology_parity.py:17`, `test_m34_regression.py` and `test_m35b_disease.py`. Its `TERRAIN_ECOLOGY_CAPS` (oracle lines ~20-27) has six terrains and lacks steppe, jungle and marsh, which are Geography 2.0 terrains. Parity for those is therefore untested through the oracle. Action: port the fixtures and add the three terrains.
4. [med] fragile: `hills` has no ecology row. `geography.py:98` lists `hills` in `PROCEDURAL_TERRAINS`, but `TERRAIN_ECOLOGY_DEFAULTS` and `TERRAIN_ECOLOGY_CAPS` (`ecology.py:50-73`) do not. Lookups fall back silently to plains (`ecology.py:475`, `.get(..., plains)`). `ffi_constants.py:12,24` maps hills to plains on purpose for Rust, so the Python side is the inconsistent part. Action: add an explicit hills row or assert on unknown terrains.
5. [med] perf: `compute_disease_severity` finds the region index with a linear scan (`ecology.py:895`). `_check_famine_yield` does linear lookups of neighbours and civs per region (`ecology.py:325,336,338`). `check_closure` scans every region's tributaries per region (`watershed.py:724`, O(n²) per turn). Action: precompute name/index maps once per tick.
6. [med] bug/docs: The watershed storage collapse is fixed for the development worlds, but the docs still describe the old state. `docs/integration/watershed.md:603-605` says B1 constants drop storage from 33-35 to 10-14 wu. The B2 refit is in force (`watershed.py:188-205`: precipitation_base 0.3488, baseflow 0.0644, cooling precipitation -0.3936). The evaluation shows storage drift of -6% to +7% over cycles 2→5 (watershed.md ~line 550). The worst held-out fold is still 2.0x (watershed.md:495). Action: mark lines 603-605 as B1 history.
7. [med] status: `flow` mode exists. `MODES = ("record_only", "flow")` (`watershed.py:115`). It requires the native extension (`watershed.py:111-113, 316, 325`), replaces the native water terms (`FLOW_REPLACED_TERMS`, 107-110) and makes the derived index the live one (`_apply_flow`, 800-841). It is default-off and only in scripts and tests.
8. [med] dead-code: `is_chokepoint` (`adjacency.py:82-105`) has no production caller. Its only uses are `tests/test_adjacency.py:80-81`.
9. [med] test-gap: `supersede_river_flood` (`watershed.py:861`, called from `emergence.py`) has no direct test. The grep of `tests/` for `supersede` returned nothing.
10. [low] perf/scale: `compute_adjacencies` recomputes `connected_components` in every repair iteration (`adjacency.py:182-195`) and sorts all regions for each under-connected region (`adjacency.py:163-170`). Both are O(n²)-ish, and both are template-only (≤12 regions by default). `_find_articulation_points` (`adjacency.py:207-228`) is recursive, with no recursion-limit guard in `src/`. Scale impact unverified.
11. [low] sim-depth: Fish stock has no climate input. `step_fishery` (`fisheries.py:64`) takes only stock, base yield, potential yield, workers and config. Its only lever is labour, so a climate or disease shock cannot reduce it directly.
12. [low] dead-code (weak): `check_food_yield` (`ecology.py:94`) is used only by `tests/test_ecology.py`, `tests/test_nomads.py` and two scripts. It is not dead, but it has no production caller.
13. [low] docs: `ecology.py` docstring (lines 1-10) still describes the pre-M54a split. Light touch only.

**Simulation depth**
- Climate: add per-region seasonality or a second long cycle (the 75-turn period is a single global knob), and wire cluster harvest shocks to fish and forest, not just crops and water.
- Disasters: only four types (`climate.py:242-247`), each tied to one terrain. Add volcanic or drought-linked disasters with a terrain mix, and link them to the watershed (floods already reach it via `_apply_flow`).
- Rivers: the economy already discounts river transport (`economy.py:370-540`), but rivers do not carry capacity, disease or seasonal flow beyond the watershed account. A river-depth or navigability term would make them real arteries.
- Fisheries: a climate and temperature input to `step_fishery` and a shared stock across adjacent coasts would make fish a regional resource rather than a per-slot one.
- Map scale: `_betweenness` is exact up to 400 regions and samples above that (`geography.py:522-530`). The Voronoi raster cost grows with cells times pixels (`geography.py:588-`). Neither has been timed at larger sizes; unverified.
