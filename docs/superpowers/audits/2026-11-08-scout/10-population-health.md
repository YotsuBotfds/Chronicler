## 10 Population and public health
**Map**
- Epidemic core: `epidemiology.py` (1192 lines). Five pathogens in a frozen table (`PATHOGENS`, line ~80), one SEIRS recursion per region and pathogen (`_step`, ~line 690), deaths via `drain_region_pop` (`_apply_deaths`).
- Turn hook: `tick_epidemics` runs in Phase 1. Its order is population absorb, care, techniques, cities, public-health crowding, introductions, SEIRS, deaths, reports, mutation, civ responses, quarantine.
- Public health (`public_health.py` 808 lines, `_state` 88 lines): environment factors, grain supply, guards, care funding, and advisory `report_targets` that feed quarantine.
- Quarantine: `quarantine_rules.py` (928 lines) gives modes legacy, none, cost_only and closure. Legacy is the default.
- Care: `epidemic_care.py` (898 lines) plus `health_care*` (health_care.py, codec 701, mechanics 640, capture 312). Rust counterparts are `chronicler-agents/src/health_care.rs` (576) and `health_care_observation.rs` (418).
- Regional and mobility helpers: `regional_population.py`, `refugee_routing.py`, `household_mobility_state.py`, `kin_root_exposure.py` (330, used by scripts and tests).
- Consumers: `main.py` flags via `batch_manifest.py`, `livelihoods.py` registry, and `viewer/src/lib/publicHealth.ts`.

**Findings**
1. [high] bug — The attribution-to-health coupling is real and is the default. `public_health.py:17` sets `DISPLACEMENT_CROWDING=0.25`. `environment_factors` (`public_health.py:425-438`) multiplies susceptibility by `1 + 0.25 * displaced_share` under `crowding="legacy_displacement"`. `displaced_share` counts open displacement spells, which are motive-classified and include hunger-driven moves (`residence_ledger.py:~135`). The corrected `density_only` mode sets the factor to 1.0. Its comment at `public_health_state.py:44-46` says the legacy default is kept on purpose ("persisted default is historical ... no promotion"). Hence the default is deliberate, but it still couples motive classification to deaths.
2. [high] fragile/docs — Screens and product disagree on the default. `scripts/cw_rework_screen.py:468,673` default `--public-health-crowding` to `density_only`. The product default (`public_health_state.py:46`) and `tests/test_residence_exposure.py:454` use `legacy_displacement`. Any "corrected" result from the screen is not the shipped configuration.
3. [high] sim — Several routes can raise deaths, which matches the held evaluation. (a) Hunger raises susceptibility through `_modifiers` (`epidemiology.py`), and it also creates displacement spells that raise the legacy crowding factor, so hunger is counted twice. (b) Under closure with the migration channel, `quarantine_rules.py` refuses refugee moves, which keeps people in sick regions and raises density. (c) `_modifiers` crowding (population over capacity, `CROWDING_SUSCEPTIBILITY=0.5`) and the `--cities` susceptibility multiplier (`epidemiology.py` ~583) both act on density. Unverified: the size of each effect. It needs a counterfactual run, which this scout did not do.
4. [med] bug — Mislabelled provenance. `public_health.py:438` sets `crowding_source_turn` to `world.turn` for `density_only`. Density is read from current `region.population` at tick time, but the label is inconsistent with the T-1 frame used for everything else. `narration_provenance.py:452-458` checks this field.
5. [med] duplication/complexity — Units mixed in the advisory cost. `report_targets` (`public_health.py:~742-760`) adds `food_cost += ab[TRADE]` (raw edge weight) to a cost that otherwise uses `CONTACT_WEIGHTS`. It also adds a hard-coded `2.0 * len(routes)`, and compares the result with `LIFE_VALUE=100` hazard units.
6. [med] fragile — `_apply_deaths` (`epidemiology.py` ~826-832) records `last.append((j,k,whole))` but sets `deaths[j] = actual` from `drain_region_pop`. If `actual != region_deaths`, the per-pathogen tolls no longer sum to the region total.
7. [med] docs/contract — `DEFAULT_ENABLED_FOR_NEW_WORLDS = True` (`epidemiology.py` ~line 70) makes epidemiology on by default for new worlds. AGENTS.md says experimental features stay default-off. The docstring cites a 2026-10 gate, so this is a documented decision that conflicts with the written contract. Owner decision needed.
8. [low] dead-ish — `recent_arrival_share` and `arrival_diagnostics_complete` are computed into environment rows (`public_health.py:~431-436`). Only the viewer reads them (`viewer/src/lib/publicHealth.ts:18,85,115-116,130`), plus a provenance key list (`narration_provenance.py:465-466`). No decision reads them.
9. [low] perf/duplication — `_modifiers(region, ...)` is recomputed per row in `_reports` and `_civ_responses`, and `region_hunger` runs on each call (`epidemiology.py` ~933, ~961).
10. [low] fragile — `quarantine_rules.py` `decide`: `decided[...] = _report_cause(...) or "" if key in reports else ""` relies on conditional precedence. It is correct but hard to read.
11. [med] duplication — The care observation layout is written by Rust `health_care_observation.rs` (`append`/`u32`/`f64` helpers) and parsed by Python `health_care_observation_codec.py` (`_Cursor`, `_uint`). The two layouts are maintained by hand. The 701-line codec is consumed by `health_care_capture.py` and tests. Unverified: whether a single schema source exists.
12. [med] test-gap — `epidemiology.py` has no fresh-build native check here. Rust `demographics.rs` (655) was not read, so the population dynamics it drives against Python's `regional_population.py` are unverified.

**Simulation depth**
- Demography: no age structure, fertility or mortality by age; births arrive as susceptible newcomers (`_absorb_population`, `epidemiology.py` ~line 555).
- Disease: no seasonality beyond `SUBSTEPS`, no vaccination or medicine tiers beyond the CFR multiplier, and mutation only exists for fever (`escape` is 0 elsewhere). Immunity 0 means lifelong (pox, `immunity_turns=0`), so the model is SEIRS in name only for that pathogen.
- Nutrition: hunger feeds susceptibility and CFR (`HUNGER_SUSCEPTIBILITY`, `HUNGER_CFR`) but not nutrition-specific pathogens or child mortality.
- Endemic disease: only a `endemic_severity` multiplier on spillover (`ENDEMIC_SPILLOVER_CAP=3`); no persistent endemic prevalence state.
