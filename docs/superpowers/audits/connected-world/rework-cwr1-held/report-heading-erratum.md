# CWR1 report heading erratum

The unchanged raw [report](report.md), SHA256
`e5d64f1658265a64ed100d158d650d29eed1f0247d77ea980599c3a145eaf2c3`,
inherits these three generic captions:

> Primary outcomes (arm minus control on each world; non-activated worlds excluded)
>
> Secondary outcomes (arm minus control on each world; non-activated worlds excluded)
>
> Harm panel beside every comparison (each arm minus its control; non-activated worlds excluded)

For **CWR1**, replace that caption interpretation with:

> All enrolled matched worlds included; actual mechanism activation reported separately.

The numeric data do not exclude inactive worlds. Every non-root run carries
the CWR1 eligibility label `activated: true` with the explicit explanation
that every enrolled world enters; the root is specially recognized as the
root. This label is not evidence that a mechanism acted. All six worlds in
each stratum enter every primary comparison and interaction. CWR-specific
supplemental contrasts explicitly request no activation filter. Template
work-decision and public-health null cases remain included.

Independent arithmetic checked the complete 144-run matrix and all six
rendered primary rows against their six enrolled world differences. No
world, run, observed harm or null was selected away. The defect is in the
inherited captions, not in sample selection or arithmetic.

This adjacent erratum preserves the original report bytes, frozen source,
extractor, protocol, outcome definitions and runtime identities. No simulation
was rerun or changed. Read the raw report with this clarification and the
final evidence review; do not treat the generic eligibility column as a
measured activation outcome or infer efficacy from an unactivated mechanism.
