# Source-only four-header observer

This is a separate named volume contract for the original failed-checkpoint
archives. It preserves the qualified 5f diagnostic, source 3386/846 and all old
A/W input limits and full-completion NULL slots. Its own activation pin is NULL.
No archive acquisition, scientific fix, recovery, CP restore or World is granted.

The exact inputs total 5,457,873,896 bytes. Including 8 MiB output and 8 MiB
reserve fits a new decimal 5,500,000,000-byte ceiling. Source-owned admission
retains 12 GiB disk/2 GiB visible RAM initially, 3 GiB/1 GiB running floors,
2 GiB address space, 1,200 process CPU seconds, one reader CPU, and the original
1,200/300 transfer wall/CPU, 1,800/900 selected-read wall/CPU and 3,300 overall
wall deadlines. These are prospective bounds, not observed admission.

New HeaderArchivePin, explicit streaming and EOCD/ZIP64/central preflight do not
call old InputPin constructors, compressed archive admission or A preflight.
The old caps remain unchanged. Only parameterized descriptor/hash, bounded
HTTP response/metadata, durable-file and clock mechanisms are reused. Source
snapshots bind every protected helper, the old K source reference, both policy
files and the exact active workflow. K is not imported or invoked.

The index must exactly match all 1,700 original selector byte rows plus the
two selector files, within 100,000 entries, 64 MiB central and 6 GiB expanded
per ZIP. Whole compressed hashes are checked before and after reads. Only the
two selectors and four source-derived CP entries are opened. Their complete
EOF/CRC/SHA checks do not imply checks of every other CP payload. Only the two
last-valid CPs have prior whole SHA pins; first-unvalidated hashes are newly
observed under whole-ZIP identity. Selector null hashes are never replaced.

Outer ZIP deflate streaming is permitted. The CP files' inner Python/native
sections remain packed. The reader stores only each bounded header JSON,
checks typed finite unique-key JSON and contiguous packed extents, and records
unverified inner-section digest declarations. It never imports a CP loader,
inflates a section, unpickles, extracts a CP file or restores a simulator.

Observed operands, source/native/identity/lineage and old K predicate bits are
reported separately. A larger civilization count is not labelled legitimate
or invalid. The original in-memory current_identity was not separately saved;
an authenticated last-valid header is an explicit comparison reference, not a
manufactured new observation. Reader control, original control 33d, candidate 503
and native b56 fingerprints retain distinct roles.

The source input registry is a curated projection of plan 7f69 with machine-local
evidence paths removed and source-facing roles made explicit. Both bundle maps,
all 1,700 selector rows, four target rows, identity reference and volume math are
unchanged. It links root 5f qualification 1e34 and primary c56, both
selector hashes and all exact byte pins. It grants no complete physics, salvage
or full payload qualification. Source/pure/independent/root review and a separate
registered one-file activation are required before any transfer. Preserve the
first refusal without retrying or relaxing a bound.

Qualification is source-only. The first guarded run retained 43 passes and one
expected-exception-type test failure. The affected 16-case run retained 15 passes
and a second expected-exception-type fixture failure; the corrected missing-copy
case then passed alone. All 59 final cases are covered by that scoped union, with
the unchanged production reader at 2b8d throughout; a combined final 59-case run
was not performed. The exact earlier test texts and function comparisons are
retained externally. Guards recorded zero native imports, runtime factory calls
or blocked I/O; the largest synthetic fixture tree was 423,274 bytes. These are
method checks, not actual header observations or deployment admission.

The initial tiny test draft was authored by a separate agent, which is therefore
not an independent reviewer of this header implementation. Runtime source,
subsequent wiring tests and source registration remain owned by the build lane.
A separate non-author source peer and root must review before registration.
