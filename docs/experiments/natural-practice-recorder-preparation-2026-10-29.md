# Natural practice recorder preparation

This is source preparation on a separate child of `cbf6e368`, not a study
activation. The qualified producer and original C76 cohort remain unchanged.
The fresh driver, native policy, prospective freeze and CP60 continuation
qualification are separate work.

`scripts/research_practice_recorder.py` is an explicit caller-owned writer.
It imports no World, observer, simulation or native runtime. Its fixed grid
is regions 0–7 × irrigation/masonry, matching the proposed eight-seed study.
It copies only bounded public scalar observation fields, preserving numeric
types and finite floating-point values, including signed zero. It does not
read a lazy claim getter, recompute a paid RHS or infer payment from events.

Each role has one compact JSONL journal and one offset/length/SHA index.
Parent sources are 0–179; active/pause sources are 60–179. Limits remain 16
rows, 64 KiB of encoded row data and a 4 KiB envelope per frame, at most 180
frames per journal. No file per frame is created. These bytes still count
against the experiment's unchanged aggregate admissions.

A captured frame must match the exact selection/order, source, handle-local
attempt and original observer byte count. Invalid reporting becomes an
explicit unavailable slot. Original unavailable reasons, unknown source and
unknown kernel assignments stay unknown. Recorded unavailability and an
unattempted suffix have different counts; neither becomes a computed zero.

Payments are grouped by source/seat/region. Both recipe rows retain their
bookkeeping values, while the repeated group cost is counted once and checked
against the ordinary effort counter. A paid-zero recipe can have a positive
allowance. Empty event IDs remain valid for repeat payments. Valid raw
kernel/payment rows are retained even if accounting reconciliation fails;
the index records the mismatch and cannot call that trace usable. An unknown
initial counter is explicitly unobserved, not silently assigned zero.

Completed and interrupted journals remain distinct. The writer flushes each
line and fsyncs before final indexing. Partial writes and fsync failures cannot
publish a complete index. A complete grid containing unavailable frames
is not a complete usable trace. Even a usable journal index qualifies only
its bytes; the future worker/execution/source/budget seals remain required.
Caller-owned closure never retries physics.

Forty guarded metadata-only cases pass; the combined practice chunk passes all
131 cases. They use immutable public observation
dataclasses and small synthetic journals, with no World, phase, native import
or build. They cover exact floats, later commit values, sparse-event/paid-zero
bookkeeping, malformed/stale frames, unknown counters, null exposure, complete
and partial coverage, file preservation, write/fsync faults and unchanged
caller Python/NumPy RNG. The existing 110-second practice-observer chunk
includes this test file; hosted control qualification remains pending.
